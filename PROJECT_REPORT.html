1. Executive Summary & Abstract

Section 01

This project report presents the architectural design, implementation, and quality assurance audit of a production-grade personal portfolio website developed for Nagalambika D Koralli. The solution highlights technical accomplishments, academic credentials, and practical software engineering capabilities.

Rather than utilizing off-the-shelf templates or heavyweight JavaScript frameworks, the website is engineered strictly using semantic HTML5, CSS3 Custom Properties, and modular Vanilla JavaScript. This architectural choice delivers lightning-fast load times, complete search-engine accessibility, and total visual customization.

Crucial design milestones include an ergonomic 100vh full-screen desktop hero section, zero personal photographs, a custom-crafted SVG illustration for engineering milestones (about-visual.svg), a refined Warm Editorial Linen & Forest Pine / Terracotta theme, and strict factual alignment with collegiate and internship records.

2. System Architecture & UI/UX Design System

Section 02

The user interface is governed by a Warm Editorial design system that completely replaces standard cold blue-and-white palettes and high-contrast dark themes.

Design Token Color Value Visual Purpose
--bg-page Warm Alabaster Linen (#FBF9F5) Organic, eye-friendly light page canvas
--bg-card Crisp Studio White (#FFFFFF) Elevated card surfaces with subtle borders
--color-primary Deep Forest Cypress / Pine (#1E3A34) Brand anchor, navigation links, primary action buttons
--color-accent Warm Terracotta Rust (#C86D51) Interactive highlights, focus states, and badges
--text-primary Deep Espresso Charcoal (#1C1E1D) High-contrast headline and body typography

Hero Section Viewport Ergonomics

The desktop hero section is engineered to take exactly min-height: calc(100vh - var(--nav-height)) with centered flex alignment. Visitors on laptops and desktops see the complete introduction, live status indicator, primary action buttons ("Featured Projects" and "About Me"), and a 3-card architectural showcase deck without scrolling.
